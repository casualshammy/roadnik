# ТЗ: Интеграция MAUI клиента с Discord
Общая цель: позволить пользователю транслировать своё примерное местоположение (район города, округ...), а также ссылку на трансляцию своего местоположения в виде расширенного статуса Discord (аналогично playing now функционалу).

## Настройка интеграции
- В окне настроек должен быть отдельный пункт, позволяющий получить авторизационные данные для взаимодействия с сервисом Discord.
- В окне настроек должна быть возможность быстро выключить или включить интеграцию с Discord.
- В окне настроек должна быть возможность добавить пользовательскую строку (статус), например, "Катаюсь с ветерком в горах". Этот статус должен добавляться к статусу в Discord.

## Трансляция
- При включении трансляции своего местоположения необходимо устанавливать статус (аналогично playing now функционалу) в Discord.
- При успешной отправки очередной точки местоположения статус в Discord должен обновляться.
- При завершении трансляции нужно убирать статус из Discord.
- Подключение к серверам Discord должно быть активно только во время активной трансляции - для экономии заряда батареи.
